Selected projects

Lake Shore 335 Controller GUI

A standalone Windows desktop application for the Lake Shore Model 335 cryogenic temperature controller, written in Python with PyQt5. It scans for available COM ports, connects to the instrument over serial, and polls it in the background so the window stays responsive while a measurement runs. Both sensor inputs are read live and plotted against time, and the setpoint, PID terms, ramp rate and heater range can all be changed from the application instead of the front panel. Instrument communication lives in its own module, separate from the interface, and the whole thing is packaged with PyInstaller so it runs on a lab machine with no Python installed.

Python · PyQt5 · pySerial · Matplotlib · PyInstaller

RamanSuite

A general-purpose Raman spectroscopy analysis application for MATLAB, built around a single data structure that covers a spectral series taken against any variable temperature, pressure, electric field. So an analysis written once works on all of them. The window is a six-stage pipeline: load a folder of spectra, correct them (dark, wavenumber calibration, instrument response, Bose factor), fit a composite model to every spectrum, follow each peak across the series with quality flags, fit the temperature dependence with anharmonic and order-parameter models, and export a publication figure together with the numbers behind it. The interface is a thin shell over a library, so every button is a function that can also be called from a script. Every folder of output carries a record of exactly what produced it, and nothing is silently overwritten.

MATLAB · programmatic app · curve fitting · instrument-agnostic file I/O
